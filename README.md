# DM Toolkit

Herramienta para Dungeon Masters de D&D 5e: bestiario, generador de botín y bandeja de dados.

🌐 **Aplicación web:** https://TU-ENLACE.vercel.app
📱 **APK Android:** en la sección [Releases](../../releases)

## Tecnologías
React, Vite, JavaScript, CSS, CapacitorJS. Datos de [dnd5eapi.co](https://www.dnd5eapi.co/api/).

## Ejecutar en local
npm install
npm run dev
